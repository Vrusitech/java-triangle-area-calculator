# Triangle Area Calculator (Java)

A simple CLI application written in Java that calculates the area of a triangle based on user input.

## 🚀 Features
- Accepts decimal values for base and height.
- Calculates area using the standard formula: `(base * height) / 2`.
- Properly closes input streams to prevent memory leaks.

## 💻 How to Run
1. Clone the repository:
```bash
git clone https://github.com/Vrusitech/java-triangle-area-calculator.git
```
2. Compile the Java file:

```Bash
javac Calculator.java
```
3. Run the compiled program:
```bash
java Calculator
```
